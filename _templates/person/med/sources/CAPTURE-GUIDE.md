# Capturing source documents (scanning guide)

This is the shared procedure for capturing scans. It is read from
`_templates/person/med/sources/CAPTURE-GUIDE.md` in any person's session and is not copied into a
person's folder.

The scan is the permanent **grade-A** evidence — OCR, profile and handouts are all rebuilt from it,
so capture quality is the one thing that can't be fixed later. A few habits keep it reliable.

## Tool

- Use a **document scanner**, not the raw camera: on iPhone, **Notes → camera icon → Scan
  Documents** (or the Files app). It auto-detects edges, de-skews, and keeps multi-page docs together.
  Notes keeps scans in iCloud when Notes syncs with iCloud; check that setting if health documents
  should stay on the phone.
- Prefer the built-in scanner over third-party apps (those often round-trip images through their own
  cloud — avoid for health data).

## Settings

- **Colour** filter — *not* Black & White. B&W drops red out-of-range flags, stamps, faint thermal
  print and pen annotations — all signal.
- **Full resolution**; don't downscale or heavily "enhance".

## Technique

- **Even, indirect light**; kill glare (the enemy on glossy lab paper). No flash.
- **Flat and square**; capture the **whole page including margins/footers** (dates, reference
  ranges, "Strona 1/2" markers).
- **Check sharpness before moving on** — motion blur is the one unrecoverable failure. Zoom to 100 %:
  if you can read the smallest digit, so can the model.

## One document = one file (important)

- Add **all pages of a report into the *same* scan** before sharing, so a report = one multi-page PDF.
- Don't save pages of one report as separate files; don't combine two different documents — or two
  different people — into one file. (Separate files make a missing page easier to overlook; mixing
  people risks the #1 error, a person mix-up.)

## Organisation & export

- Keep each person's files in **their own folder**. No need to rename on the phone — intake renames
  to `YYYY-MM-DD__issuer__desc`.
- Share as **PDF** (multi-page preserved); save into that person's folder.
